M1kunRead

В разработке · BETA 1.0B

Удобная и сверхбыстрая утилита для записи ISO образов на USB-накопители и мгновенного создания загрузочных носителей. Просто выберите образ, укажите флешку и дождитесь проверки целостности.

Основные функции

  • ✓ Запись ISO файлов на USB с высокой скоростью
  • ✓ Поддержка режимов UEFI и Legacy
  • ✓ Детализированное отображение прогресса записи
  • ✓ Поддержка файловых систем FAT32, NTFS, exFAT
ISO на любые системы

Поддерживаемые системы

🪟

Windows

Запись образов Windows 7, 8, 10, 11

🐧

Linux

Ubuntu, Fedora, Arch Linux и др.

Системные требования

ОС: Windows 7 или новее
Интерфейс: USB-порт для подключения накопителей (желательно USB 3.0)
Память накопителя: Минимум 4 ГБ свободного места на USB-флешке
Важно: Необходимы права администратора для записи на низком уровне
